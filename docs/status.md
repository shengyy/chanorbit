# Test status

Version 0.2.0, schemas `chanorbit.geometry/2`, `chanorbit.stages/3`, `chanorbit.levels/3` and `chanorbit.signals/1`. This document records what this repository's own tests and builds cover. Gate commands are in [CONTRIBUTING.md](../CONTRIBUTING.md).

## Covered

|---|---|

## Not covered

- The engine's `non_finite` reasons and the non-finite candidate path. The command line rejects such input before computation, so they are reachable only through the library, and have no test there.
- `min_stroke_bars` other than 4 and 6 (library only; the command line uses 6).
- `stages` baselines are synthetic daily series only; no intraday or real-data stage case is committed.
- `levels` baselines are synthetic apart from three transformed single-level cases.
- Native execution on a Linux x86_64 host; only container emulation was run. Windows is not a target.
- A finished stroke removed by the two-stroke reopening of *Extension* or *Append* ([strokes](structure-contract.md)). The check that the last stroke never returns to the stroke before it runs on the committed baselines only; a local 17-bar synthetic series (not committed) makes a finished down stroke disappear on the next input, and a local replay of 65,294 prefixes of 75 real series (not committed) changed a confirmed fractal pair on 25 inputs where 0.1.1 did not.
- `signals` has no baseline file and no real-data case; its rules are tested on the hand-built series above. Not covered: a parent level whose departure is a non-member stroke, the finer series not covering the parent bar of `D`'s high (no child time, `buy` stays `null`), several local centres in one span, a `sell` whose `U` is the extending last stroke, and an observation row for `sell` other than its single `triggered` stage.
- Long series that form no stroke (quadratic time, see [architecture.md](architecture.md#data-flow)) have no timing test. Performance has no threshold or test; `cargo run --release --example bench` (`--signals` for `signals` requests) gives local readings only ([architecture.md](architecture.md#data-flow)).
